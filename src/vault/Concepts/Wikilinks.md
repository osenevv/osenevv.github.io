# Wikilinks

Obsidian-style `[[Note Title]]` links inside Markdown. They are first-class: the parser turns them into internal links, backlinks, and graph edges without a separate link database.

Aliases use a pipe: `[[Long Note Name|short label]]`. Headings use `#`: `[[Note#Section]]`.

This site uses the same syntax in vault notes. [[ZettelLinker]] can suggest new wikilinks from semantic similarity when two notes share an idea but not vocabulary.
