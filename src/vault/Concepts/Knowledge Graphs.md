# Knowledge Graphs

Notes as nodes, links as edges. In Obsidian the graph emerges from [[Wikilinks]]; in a database it's explicit triples. Either way the structure carries information the text alone doesn't.

## Graph + vectors
Links are precise but sparse — they only exist where someone wrote them. [[Vector Search]] is fuzzy but complete. Combining both is the idea behind [[ZettelLinker]]: use vectors to propose edges, let a human accept them.

The graph on the [[Home]] note is this site's link structure, computed from the Markdown at build time.
