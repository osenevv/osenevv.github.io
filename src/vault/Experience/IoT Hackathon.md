# IoT Hackathon — 1st place

Won a 48-hour hackathon in Moscow with a smart-home automation prototype: sensors, a control hub, and automation rules wired together under deadline.

## What shipped
End-to-end path first: one sensor → hub → one light relay → then more rules. We cut scope on polish and kept the live demo reliable.

The lesson I keep: ship the pipeline, then harden. Same approach I use for [[Agentic Workflows]] and LLM features today — prove the loop, then optimize latency and tests.
